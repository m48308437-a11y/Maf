# MFA — سایت واقعی انیمه

## اجرا

1. Node.js 18+ نصب باشد.
2. داخل پوشه پروژه اجرا کنید:
   npm install
   npm start
3. مرورگر: http://localhost:3000

## حساب‌های نمونه
- مدیر: admin / admin123
- کاربر: mfauser / user123

برای محیط واقعی حتماً رمزها و SESSION_SECRET را تغییر دهید و HTTPS فعال کنید.
